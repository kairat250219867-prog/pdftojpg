# Редактор PDF

Оконное приложение на Python для работы с PDF: правка, разделение, объединение, экспорт в JPG / PNG.

## Запуск

Нужен Python 3.9+:

```
pip install -r requirements.txt
python pdf_editor.py [файл.pdf]
```

На Windows можно просто запустить `pdf_editor.bat` — он сам поставит PySide6 и PyMuPDF при первом запуске.
Чтобы открывать PDF двойным кликом, выберите `pdf_editor.bat` в «Открыть с помощью».

## Возможности

**Страницы** (панель миниатюр слева, можно выделять несколько через Ctrl/Shift):

- Перетаскивание миниатюр меняет порядок страниц (или Ctrl+↑ / Ctrl+↓)
- Поворот (Ctrl+L / Ctrl+R), удаление (Del), пустая страница
- **Вставить PDF / картинку** (Ctrl+I) — в конец, начало, до или после текущей страницы
- **Собрать PDF из файлов** (Ctrl+N) — объединить несколько PDF и картинок в новый документ
- Перетаскивание файлов в окно — открыть или добавить в документ

**Разделение** (Ctrl+D): каждая страница отдельно, по N страниц или по диапазонам (`1-3, 4-10, 11-`).
**Извлечь выделенные** — сохранить выбранные страницы в новый PDF.

**Экспорт в JPG / PNG** (Ctrl+E): все, выделенные страницы или диапазон; разрешение (dpi) и сжатие JPG.

**Правка** (вторая панель инструментов):

| Инструмент | Что делает |
|---|---|
| Текст | Щелчок — добавить текст (цвет и размер шрифта на панели) |
| Править текст | Щелчок по строке — заменить её текст |
| Стереть | Удалить всё содержимое в выделенной области |
| Маркер | Подсветить область |
| Рамка | Нарисовать прямоугольник |
| Карандаш | Рисование от руки, подпись |
| Картинка | Вставить изображение в выделенную область |

Отмена / повтор — Ctrl+Z / Ctrl+Y. Масштаб — Ctrl+колёсико, Ctrl +/−, «По ширине» (Ctrl+0).
Поддерживаются PDF с паролем.

## Ограничения

- «Править текст» работает с текстовыми PDF; в отсканированных документах текст — это картинка,
  там используйте «Стереть» + «Текст».
- При замене текста используется системный шрифт (Arial на Windows), а не шрифт документа.
